# Duck Catalog

This is a simple Vite and React website to learn about modals, counters, and other components. It is themed as a duck catalog. There is a functioning search bar and containers are rendered from a duck array. 

It was intended to also have a navigation bar that switches to a goose catalog instead, but it was never implemented. There is also very beginner conditional rendering between ducks and geese.
